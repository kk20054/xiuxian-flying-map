# 02 · The UI, recreated in Godot

Every screen of the demo's UI exists in the port as an editable scene, styled from one theme whose values are the demo's
CSS. The pixel-level spec of the original (positions, sizes, colours, fonts, timings) is in
[07 · UI, flight, camera, the 舆图](../07-ui-flight-camera-map.md) §1–2; this page is the map from that spec to Godot.

## How it is built

- **Theme** `godot/ui/theme/ink_theme.tres` (set as the project theme). Default font Noto Serif SC 400 14 px. Each CSS
  class is a **theme type variation** (StyleBoxFlat + fonts/colours), so a node only needs `theme_type_variation`:
  `Chrome`, `ChromePad`, `Seal`, `Seal46`, `SectTag`, `SectTagSel`, `SectTagNear`, `SectTagMinor`, `Pin`, `PinSel`,
  `PromptPill`, `HintPanel`, `KeyCap`, `Pill`, `Quote`, `ToastPanel`, `DebugHeader`, `CardFooter`, `PadPanel`, `KnobPanel`,
  and buttons `LegendButton`, `ZoomButton`, `ResultButton(Act)`, `ModeSeg(On)`, `GoButton`, `FooterButton`, `Chip`,
  `CloseButton`, `SmallButton`, `BoostButton`, plus `SearchEdit` (LineEdit).
- **Scenes** `godot/ui/*.tscn`, one CanvasLayer each at the demo's z-order. They are generated by
  `godot/tools/build_scenes.gd` (run `godot --headless --path godot res://tools/build_scenes.tscn`) so they start out
  valid and identical to the CSS; after that, edit them in the editor like any scene (and stop re-running the builder, or
  port your edits into it).
- **Behaviour** `godot/scripts/ui/*.gd`, one per scene; nodes are found by unique name (`%Name`).
- **Design tokens** `godot/scripts/ui/ui_util.gd` (`UIUtil.SILK`, `INK`, `CINNABAR`, `JADE`, `CHROME`…), font helpers
  (`UIUtil.brush()`, `UIUtil.serif(weight)`), `UIUtil.ls()` for LabelSettings with the CSS text-shadow glows,
  `UIUtil.vertical()` for 竖排 text, `UIUtil.spaced()` for letter-spacing.

## CSS → Godot translations used

| CSS | Godot |
|---|---|
| `writing-mode: vertical-rl` (tags, seals, intro title) | one character per line (`UIUtil.vertical`), centred; `line_spacing` stands in for letter-spacing |
| `letter-spacing: .3em` | `FontVariation.spacing_glyph = size × em` (`UIUtil.spaced`) |
| `text-shadow: 0 0 8px #f6f0e0` (ink on silk) | `LabelSettings.shadow_size = 8`, `shadow_offset = 0`, shadow colour |
| `text-shadow: 0 0 3px #1b2523 ×2` (labels on the dark map) | `LabelSettings.outline_size = 3` + a soft shadow |
| `box-shadow: 0 8px 24px rgba(0,0,0,.28)` | `StyleBoxFlat.shadow_size = 12, shadow_offset = (0, 8)` |
| `box-shadow: 0 0 0 200vmax …` (the plate) | four rects drawn around the projected world rect |
| `backdrop-filter: blur(8px)` | not reproduced (the 0.9-alpha fill dominates); add a `hint_screen_texture` blur behind a panel if wanted |
| `transition: opacity .7s` | `create_tween().tween_property(node, "modulate:a", …, 0.7)` |
| `transform: translate(-50%,-100%)` (tags anchored at the pin) | `position = screen − anchor_offset()` each frame after the camera moved |
| `@media (pointer:coarse)` | `DisplayServer.is_touchscreen_available()` |
| `@media (max-width:640px)` | `info_card.gd` / `intro_ui.gd` `_layout()` on `size_changed` |
| `line-height: 1.85` | `LabelSettings.line_spacing = round(size × 1.85 − font.get_height(size))` (`info_card.gd → _gap`) — Godot adds the gap *between* lines, CSS sets the whole line box |
| CJK line breaking (no `。、，` at a line start) | `autowrap_mode = AUTOWRAP_WORD_SMART` (ICU line breaks); `AUTOWRAP_ARBITRARY` breaks before punctuation |
| `img { width:100%; height:auto }` | `TextureRect.expand_mode = EXPAND_FIT_HEIGHT_PROPORTIONAL` + `STRETCH_KEEP_ASPECT` (`EXPAND_FIT_WIDTH_PROPORTIONAL` collapses to 0 height inside a VBox) |
| `pointer-events: none` (HUD, banner) | `mouse_filter = MOUSE_FILTER_IGNORE` on the whole subtree (`build_scenes.gd → _ignore_mouse`) |
| wheel over a panel doesn't zoom the world | `mouse_force_pass_scroll_events = false` on panels (`_stop_wheel`); the director reads the wheel in `_unhandled_input` |
| `:hover` / `:active` / `.on` | Button styles `hover` / `pressed` / `hover_pressed` set separately — `hover_pressed` falls back to `pressed`, so a toggled legend button looked "pressed" while hovered |
| `input:focus` swallowing keys | the director ignores keys while a `LineEdit` has focus and calls `gui_release_focus()` on a click in the world |

## Restyling tips

- Change a colour everywhere: edit the token in `ui_util.gd` and the StyleBox in `build_scenes.gd → _theme()`, re-run the
  builder; or open `ink_theme.tres` in the editor's Theme panel.
- New label style for a place category: `map_chrome.gd → _settings(cat)`.
- Card layout: `info_card.gd → _fill()` builds the body from the place dictionary (fields: `type, ally, name, crumb,
  lead, body[], note, chips[]`) — `places.json` is the content, editable without code.
- Fonts: the shipped TTFs are subsets (GB2312 level-1 + the characters the demo uses that the fonts have). Replace them
  with the full Google Fonts files if you add new text. Some UI symbols are in neither font: Noto Serif SC lacks ⌂ (zoom
  home), ✦ (秘境), ▮ (宗门), ◩ (势力), ⋰ (韩立行迹) and ● (the card's ally chip), 马善政 also △ ◆ ·. They render only
  through the OS font fallback and show as boxes where there is none (Web export, minimal Linux): give the FontFiles a
  symbol font (e.g. a DejaVu Sans subset) as `fallbacks`.
